Stage 3 v3 syntax patch
=======================
Corrected the AMPL indexing expression in main_stage3_pilot.run.

Incorrect:
  for {s in S: s=4, c in CASES, d in DURS, tau in PILOT_STARTS: ...}

Correct:
  for {s in S, c in CASES, d in DURS, tau in PILOT_STARTS:
        s = 4 and tau+d-1 <= NPER[s]} { ... }

In AMPL, all indexing declarations must appear before the single ':' filter.
No mathematical formulation, input data, solver option, or full-sweep logic was changed.
