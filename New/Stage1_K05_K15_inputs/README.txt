Stage-1 scenario sweep inputs: K=5,...,15

Each Kxx folder contains:
  - planning_scenarios_2025.dat
  - planning_profiles_2025.dat
  - scenario_map_Kxx.csv

For a manual run:
1. Copy the two .dat files from the desired Kxx folder into the Stage-1 AMPL folder.
2. Keep p2a_planning_scenarios.mod and main_planning_2025.run unchanged.
3. Run:
       ampl main_planning_2025.run
4. Save the outputs before moving to the next K:
       planning_summary.csv
       planning_scenario_summary.csv
       planning_dispatch.csv
       planned_capacities_exact.dat
       reference_design_rounded.dat

Do not run build_planning_2025_profiles.py after replacing the scenario files.

The aim of the K sweep is to evaluate planning stability as K increases using
scenario sets generated by the same methodology.
